## Programa Para Registro de Estudiantes y Control de Calificaciones

### ¿Qué es el programa?
Es un **Sistema de Control de Calificaciones** diseñado para automatizar la gestión académica de una institución, eliminando los listados manuales.
### ¿Cómo funciona?
 * **Frontend (Pantalla):** Formularios interactivos construidos con **EJS** donde el usuario puede registrar, ver, modificar o eliminar datos de los estudiantes.
 * **Backend (Servidor):** Corre sobre **Node.js y Express**. Procesa las peticiones, calcula automáticamente los promedios y valida estrictamente que la información sea correcta antes de guardarla.
 * **Base de Datos:** Los datos se guardan de forma persistente y ligera en un archivo **JSON** (bd.json), asegurando que no se borren al apagar el sistema.

---

Es una herramienta administrativa rápida, intuitiva y segura, ideal para optimizar el control de notas y mantener la información protegida contra registros falsos o duplicados.
